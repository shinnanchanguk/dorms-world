# 협력 패턴 목록

아이디어를 낼 때 개념의 뼈대와 엮는 재료다. 패턴 하나가 답은 아니고, 뼈대와 만나야 스테이지가 된다. 셋째 칸은 예일 뿐이다. 수업의 물건과 동작에 맞는 장치가 없으면 새로 만든다(`kit/STAGE_FORMAT.md` '새 물건 만들기', `kit/DEVICE_GUIDE.md`).

| 패턴 | 무엇 | 이렇게 만들 수 있다(예) | 잘 맞는 뼈대 |
|---|---|---|---|
| 같이 힘 모으기 | 한 물건을 여럿이 함께 다룬다 | 같이 미는 상자, 여럿이 밟는 단추 | 양, 합, 비율, 최소 조건 |
| 서로 발판 되기 | 내 몸이 남의 길이 된다 | 머리 위 올라타기 | 순서, 단계, 높이와 거리 |
| 누군가는 남기 | 한 사람이 눌러 주는 동안 다른 사람이 지나간다 | 밟는 동안만 놓이는 다리 | 조건이 유지되는 동안, 원인과 결과 |
| 정보 나눠 갖기 | 사람마다 다른 단서를 보고 말로 맞춘다 | 사람마다 다른 글이 보이는 표지, 사람마다 다른 모습의 물건(없으면 새로 만든다) | 분류 기준, 바꾸기, 관점이 다름, 조건 모두 만족 |
| 역할 나누기 | 사람마다 할 수 있는 일이 다르다 | 색깔별 문, 한 사람만 들 수 있는 도구(새 물건·새 움직임으로 만든다) | 부분과 전체, 분업, 순환 |
| 동시에 하기 | 같은 때에 다른 자리에서 해야 한다 | 떨어진 단추 여러 개 | 동시 조건, 균형 |
| 차례 지키기 | 정해진 순서로 해야 풀린다 | 순서를 기억하는 장치: 새 움직임 파일 하나로 만든다(본보기 `platform/behaviors/toggle.ts`) | 절차, 인과의 사슬 |
| 함께 도착 | 한 명이라도 빠지면 끝나지 않는다 | 열쇠와 문(모두 들어가야 끝) | 모든 뼈대의 바탕 |
| 나눠서 맞추기 | 전체 인원을 조건에 맞게 여러 자리에 나눈다 | 필요 인원이 다른 단추 여러 개 | 분배, 비, 방정식의 해 |
| 양쪽에서 같은 일 하기 | 두 편이 같은 때에 같은 만큼 해야 균형이 유지된다 | 단추 둘을 같이 밟기, 양쪽에서 상자 밀기 | 등식의 성질, 균형, 보존, 대칭 |
| 만들고 나르기 | 방에 있는 사람이 도구의 모양을 정하고, 현장에 있는 사람이 본 것을 말해 주며 들어 나른다 | 그래프 공장(찍는 방, 손잡이 방, 출구, 여럿이 함께 드는 그래프 조각) | 식과 그래프, 함숫값, 정의역, 접선, 볼록성 |

바탕이 된 것: 협력 게임 설계 패턴 연구(Rocha 외 2008, El-Nasr 외 2010), 협력 학습의 직소 구조와 긍정적 상호의존(목표, 자원, 역할).

- 2명일 때도 성립하나? 30명일 때는 누가 무엇을 하나?
