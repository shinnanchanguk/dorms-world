# 도름스 월드 스테이지 키트

이 폴더에서 선생님이 "게임", "스테이지", "협력 게임", "수업 자료로 만들어" 같은 말을 하면 `kit/skills/coop-game/SKILL.md` 를 읽고 그 순서를 따른다.

- 처음에 개발 서버(`npm i`, `npm run dev`)를 띄워 선생님께 화면을 열어 드리고, 수업 자료를 달라고 하거나 무엇을 게임으로 만들지 묻는다.
- 계획 단계(플랜 모드 포함)에서는 코드를 쓰지 않고 SKILL.md 의 1~6단계(준비, 자료 읽기, 함께 아이디어 내기, 여쭙기, 브로콜리 점검, 설계서)를 한다. 설계서를 선생님이 확인한 뒤에만 만든다.
- 스테이지는 `packs/<교과>/<팩>/` 아래 파일로 만든다. 그림은 `kit/ART_GUIDE.md` 대로 글자로 그린다. 판에 없는 것은 판(`platform/`, `src/`)을 고쳐 새로 만든다(`kit/DEVICE_GUIDE.md`). 판에 있는 것만으로 되게 하려고 아이디어를 줄이지 않는다.
- 화면에 나오는 글은 쉬운 한국어로 쓴다. 이모지와 긴 줄표를 쓰지 않는다.
- 선생님이 직접 해 보고 좋다고 하신 뒤에 `npm run submit -- <교과>/<팩>` 으로 도름스에 보낸다(도름스 로그인만 있으면 된다. GitHub 계정은 필요 없다).
- 형식은 `kit/STAGE_FORMAT.md`, 설계서 틀은 `kit/DESIGN.template.md`.
