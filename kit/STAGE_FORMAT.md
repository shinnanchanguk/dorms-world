# 스테이지 형식

이 문서는 **지금 판이 아는 것**을 적은 것이다. 여기에 없는 장치·칸·성질이 필요하면 판 코드를 고쳐 새로 더한다(`kit/DEVICE_GUIDE.md`). 이 목록에 맞추려고 아이디어를 줄이지 않는다.

팩 하나는 폴더 하나다.

```
packs/<교과>/<팩>/
  pack.json        팩 정보(이름, 단원, 만든 사람, 스테이지 목록)
  DESIGN.md        설계서
  things.json      새 물건 종류(있을 때만. 아래 '새 물건 만들기')
  stages/01.map.txt   글자 지도
  stages/01.json      글자의 뜻과 장치 값
  sprites/apple.txt   글자로 찍은 그림(있을 때만. 그리는 법은 kit/ART_GUIDE.md)
```

`<교과>` 와 `<팩>` 은 영문 소문자, 숫자, 줄표(-)만 쓰고 각각 40자까지다. sprites 의 그림 이름도 같다.

## pack.json

```json
{
  "id": "math/sample",
  "name": "팩 이름(40자까지)",
  "tagline": "한 줄 설명(30자까지)",
  "family": "수학",
  "schoolLevels": ["중학교"],
  "units": [{ "band": "ms2", "subject": "수학", "unit": "단원 이름" }],
  "educationalIntent": "이 게임으로 학생이 겪게 하려는 것",
  "description": "소개",
  "creator": { "nickname": "도름스 닉네임", "avatar": null },
  "players": { "min": 2, "max": 30 },
  "stages": [{ "file": "01", "name": "스테이지 이름", "difficulty": 1 }]
}
```

- `family` 는 도름스 오락실의 교과 묶음 이름과 같아야 한다: 국어, 영어, 수학, 사회, 역사, 도덕·윤리, 과학, 정보, 기술·가정, 음악, 미술, 연극, 체육, 한문·외국어, 교양, 통합교과, 창의적 체험활동, 기타.
- `difficulty` 는 1(쉬움)부터 5(어려움).
- `players.min` 은 1 부터 적을 수 있다(`"min": 1` 이면 혼자 하기가 열린다). 안 적으면 2. 혼자서도 깨지는지 직접 해 본 뒤에 1 로 둔다.
- `avatar` 는 `null` 로 둔다(만든 사람 그림은 기본 도름이로 보인다. 도름스로 보내는 길에서는 그림 파일을 받지 않는다).

## 글자 지도 (NN.map.txt)

한 글자가 한 칸(30px)이다. 줄 길이는 모두 같아야 한다. 가로 20~80칸, 세로 12~18칸.

| 글자 | 뜻 |
|---|---|
| `#` | 땅(막힌 칸) |
| `.` | 빈칸 |
| `@` | 시작 자리(한 곳. 도름이들이 이 둘레에 선다) |
| `K` | 열쇠 |
| `D` | 문(이 칸이 문의 왼쪽 아래. 문은 가로 2칸, 세로 3칸) |
| 영문 소문자, 숫자 | NN.json 의 `legend` 에서 뜻을 정한 장치 |

지도 바깥 왼쪽, 오른쪽, 위는 벽이다. 도름이가 아래로 떨어지면 시작 자리로 돌아오고, 상자가 아래로 빠지면 처음 놓인 자리로 돌아온다.

자리 약속(어기면 지도를 받지 않는다)
- `@` 바로 아래는 땅(`#`), 바로 위는 빈칸이어야 한다(도름이 키가 한 칸보다 크다).
- `D` 가 놓이는 가로 2칸, 세로 3칸은 빈칸이고 그 바로 아래 두 칸은 땅이어야 한다.
- 단추 바로 아래는 땅이어야 한다.

## 장치 (NN.json 의 legend)

```json
{
  "legend": {
    "a": { "type": "button", "need": 1, "opens": ["x"] },
    "x": { "type": "bridge" },
    "c": { "type": "crate", "need": "half" },
    "s": { "type": "sign", "texts": ["첫째 사람이 보는 글", "둘째 사람이 보는 글"] }
  },
  "hint": "처음에 화면 위에 잠깐 보이는 한 줄(60자까지, 없어도 됨)"
}
```

| type | 지도에 놓는 법 | 값 | 움직임 |
|---|---|---|---|
| `button` | 바닥 바로 위 칸에. 같은 글자를 옆으로 이어 놓으면 넓은 단추 하나 | `need`(안 적으면 1), `opens`(다리 글자 목록, 꼭 적는다) | `need` 명 이상이 밟고 있는 동안 `opens` 의 다리가 켜진다. 상자는 단추를 누르지 못한다 |
| `bridge` | 다리가 놓일 칸마다 | `mode`: `"appear"`(기본, 켜지면 생김) 또는 `"vanish"`(켜지면 사라짐) | 켜진 동안만 바뀐다. 어느 단추와도 이어지지 않으면 검사에서 떨어진다 |
| `crate` | 상자의 칸마다 같은 글자로 네모나게(예: 2×2). 붙여 놓은 같은 글자는 큰 상자 하나가 되니, 상자 둘은 다른 글자로 | `need`(안 적으면 2) | 한쪽에서 미는 사람이 맞은편보다 `need` 명 이상 많아야 움직인다(같은 수로 맞서면 멈춘다). 아래가 비면 떨어진다. 상자는 다른 상자를 밀지 못하고, 앞에 선 친구가 벽에 막히면 멈춘다 |
| `sign` | 표지를 세울 칸에 | `texts`(글 목록, 10개까지, 한 글은 40자까지) | 가까이 가면 글이 보인다. 사람마다 다른 글이 보인다(들어온 차례를 글 개수로 나눈 나머지) |
| `deco` | 꾸밈 그림을 세울 칸에(그림의 왼쪽 아래가 그 칸의 왼쪽 아래에 맞는다) | `sprite`(팩의 sprites 폴더에 있는 그림 이름) | 부딪히지 않고 도름이 뒤에 그려진다. 한 스테이지에 60개까지 |
| `thing` | 새 물건을 놓을 칸마다(그림의 왼쪽 아래가 그 칸의 왼쪽 아래에 맞는다) | `thing`(things.json 의 물건 이름) | 아래 '새 물건 만들기' |
| `goal` | 놓는 곳. 같은 글자를 네모로 이어 놓는다 | `accepts`(받는 물건 이름 목록), `opens`(다리 글자 목록), `need`(채울 개수, 안 적으면 `"all"`), `label`(8자), `sprite`(그림, 없으면 점선 테두리) | 들고 온 물건을 여기서 확인으로 놓거나, 모으는 물건을 어디서든 모으면 수가 오른다. `need` 가 차면 다리가 켜지고 꺼지지 않는다 |

그래프 공장 장치(`press`, `desk`, `out`, `stand`, `bell`, `drop`, `hive`, `basket`, `flower`, `leak`, `bucket`, `drain`, `sled`, `target`, `slot`)는 아래 '그래프 공장' 절에 따로 적는다.

적어 둔 것 말고 다른 칸 이름(오타 포함)을 쓰면 지도를 받지 않고 어느 칸인지 알려 준다. 새 칸이 필요하면 판(`platform/stage.ts` 등)에 그 칸을 더한다.

### 그래프 공장

학생이 함수식을 넣어 그래프 조각을 찍고, 그 조각을 들고 다니며 구덩이에 걸치고, 홈에 끼우고, 공과 빗물을 받고, 벌을 막고, 썰매 길을 만드는 장치 묶음이다. 본보기는 `packs/math/graph-factory`(8스테이지)와 `packs/etc/tutorial` 의 `02 그래프 찍어 들기`.

**흐름**
1. **찍는 방(press)** 에서 확인을 누르면 식 넣는 창이 열린다. `y =` 오른쪽 수식 입력기(MathLive)에 식을 쓰고 '식 넣기'를 누르면 그 공장의 지금 식이 바뀐다. 창 안 좌표평면에 곡선 모양이 미리 보인다.
2. **손잡이 방(desk)** 에서 확인을 누르면 숫자 넷을 넣는 창이 열린다: 지나는 점 x(처음 0), 지나는 점 y(처음 빈칸), x 범위 시작(처음 -2), x 범위 끝(처음 2). 창 위에 그 공장의 지금 식이 보인다. 좌표평면 미리보기(범위는 노랗게 칠하고, 점을 찍는다)와 '세워 들면' 모양 미리보기가 함께 보인다. '그래프 찍기'를 누르면 그 공장의 출구(out)에 조각이 떨어져 나온다.
3. 현장의 도름이가 조각을 들고 가서 놓거나, 거치대에 꽂거나, 바구니에 쏟는다.

창은 그 방 가까이 서 있어야 열리고, 넣을 때 판이 다시 본다(멀면 "방 안에 서서 넣어 주세요"). 창은 맞다·틀리다를 말하지 않고 모양만 보여 준다. 식이 없으면 "찍는 방에서 식을 먼저 넣어 주세요", 점이 그래프 위에 없으면 "점 (x, y) 은 이 그래프 위에 있지 않아요" 처럼 까닭만 알린다.

**모눈**: 그래프 공장이 있는 스테이지에는 모눈종이가 깔린다. **1칸 = 1 눈금**(수학 좌표 1 이 한 칸, 30px). 다섯 칸마다 진한 선과 칸 번호(가로는 왼쪽부터, 세로는 바닥부터 센 높이)가 붙는다. 그래서 학생이 구덩이 너비, 홈 모양, 표적 높이를 세어 식과 범위를 정할 수 있다.

**넣을 수 있는 식**: x 하나의 함수 `y = f(x)` 면 무엇이든 된다(상수 `0` 도 된다). 160자까지. 쓸 수 있는 것은 숫자, x, π, e, 더하기·빼기·곱하기·나누기, 거듭제곱, 제곱근과 거듭제곱근, 절댓값, sin cos tan sec csc cot, arcsin arccos arctan, sinh cosh tanh, exp, ln, log, floor ceil round, max min, sign 이다. 다른 글자(예: y, t, a)나 명령은 "쓸 수 없는 글자가 있어요" 로 받지 않는다. 너무 복잡하거나(마디 200개, 괄호 32겹 넘게) 덜 끝난 식도 받지 않는다. 식은 판이 직접 계산하고 문자열로 실행하지 않는다.

**손잡이 규칙(B안)**: 조각에는 손잡이가 하나 달린다. 손잡이는 지나는 점 (x0, y0) 에서 **그 점의 접선과 수직인 방향**으로 붙는다. 도름이는 손잡이를 늘 세워 들기 때문에, 조각 전체가 **그 점의 접선이 수평이 되도록 돌아간다**. 꼭짓점에 손잡이를 달면 그래프가 그대로 서고, 기울기가 있는 점에 달면 그만큼 기운 채 들린다. 그래서 같은 식이라도 손잡이 점에 따라 들리는 모양이 달라진다(접선과 법선).

손잡이 방 값의 약속
- 수는 모두 -50 부터 50 사이. 지나는 점은 x 범위 안에 있어야 하고, 그 점이 그래프 위에 있어야 한다(오차는 0.05 또는 값의 1%).
- x 범위 너비는 0.5 칸 이상 16 칸까지. 돌린 뒤 조각이 차지하는 가로·세로는 22 칸까지.
- 손잡이 점에서 그래프가 끊겨 있으면(예: 1/x 의 x = 0) 손잡이를 달 수 없다.
- 한 공장의 조각이 출구의 `max` 개를 넘거나 스테이지 전체가 10개를 넘으면, 바닥에 놓인 지 오래된 조각부터 사라지고 새것이 나온다(들고 있거나 꽂거나 홈에 맞은 조각은 남는다).

**들고 놓기**
- 손잡이 끝이 몸 가까이 있는 조각 앞에서 확인을 누르면 머리 위로 든다. 이미 누가 든 조각이면 함께 든다(여섯 명까지). 함께 든 사람이 세 칸 넘게 떨어지면 손을 놓은 것으로 친다.
- **무게**: 곡선 길이 5칸마다 1명씩(1~6명) 필요하다. 혼자서도 들 수 있지만 사람이 모자랄수록 느리게 걷는다(가장 느릴 때 보통 빠르기의 절반쯤).
- 앞장선 사람(처음 든 사람)이 확인을 누르면 내려놓는다. 함께 든 사람이 누르면 그 사람만 손을 놓는다.
- 놓은 조각은 돌지 않고 곧게 떨어져 땅이나 다른 조각의 곡선에 닿으면 멈춘다. 곡선 위는 발판이라 딛고 설 수 있다(위에서만 딛는다. 밑에서는 뛰어 지나간다). 구덩이로 빠진 조각은 사라진다.
- 거치대(stand) 옆에서 앞장선 사람이 확인을 누르면 꽂는다. 꽂힌 조각은 손잡이 끝이 거치대 두 칸 위에 서고, 그 자리에서 움직이지 않는다(다시 잡으면 뽑힌다).
- 바구니 옆에서 앞장선 사람이 확인을 누르면 쏟는다(0.7초 동안 공이 그 조각에 걸리지 않아 아래로 쏟아진다).

legend 에 쓰는 장치

| type | 지도에 놓는 법 | 값 (안 적으면, 범위) | 움직임 |
|---|---|---|---|
| `press` | 찍는 방. 바닥 바로 위 칸에 | `factory`(공장 이름, 기본 `"f"`, 영문 소문자와 숫자 8자까지) | 확인을 누르면 식 넣는 창이 열린다 |
| `desk` | 손잡이 방. 바닥 바로 위 칸에 | `factory` | 확인을 누르면 점과 범위 넣는 창이 열린다 |
| `out` | 출구. 바닥 바로 위에 옆으로 이어 한 덩어리(넓은 출구 하나) | `factory`, `max`(2, 1~6. 그 공장 조각이 한 번에 있을 수 있는 수) | 찍은 조각이 이 위로 떨어져 나온다 |
| `stand` | 거치대. 바닥 바로 위 칸마다 | 없음 | 조각을 꽂아 세워 둔다. 거치대 하나에 하나 |
| `bell` | 시작 종. 바닥 바로 위 칸에 | 없음 | 확인을 누르면 판(round)이 시작되어 공·비·벌이 오고 시간이 흐른다. 이미 시작했으면 "벌써 시작했어요" |
| `drop` | 공이나 비가 떨어지는 곳. 하늘 칸에(옆으로 이은 덩어리마다 하나) | `kind`: `"blue"`(기본), `"red"`, `"mix"`, `"rain"`. `every`(나오는 간격 초, 수 하나나 `[작은 수, 큰 수]`, 0.2~20. 기본 비 `[0.25, 0.5]`, 공 `[1.2, 2.2]`), `spread`(좌우로 흩어지는 칸, 3, 0~30), `red`(`mix` 일 때 빨간 공 비율, 0.3, 0~0.9) | 파란 공은 바구니에 담을 것, 빨간 공은 맞은 도름이를 잠깐 멈춰 세우고 바구니에 들어가면 둘을 뺀다. 빗물은 곡선을 따라 흐르다가 가장 낮은 곳에서 1초쯤 머문 뒤 아래로 떨어진다. 사람이 많으면 더 자주 온다 |
| `hive` | 벌집. 하늘 칸에(덩어리마다 하나) | `every`(`[1.5, 3]`, 0.4~20), `speed`(90, 30~260) | 벌이 가장 가까운 꽃으로 날아간다. 곡선에 부딪히면 튕겨 나가 사라진다. 지나가며 도름이를 쏘아 멈춰 세운다(몸으로는 못 막는다) |
| `basket` | 바구니. 바닥 바로 위에 옆으로 이어 한 덩어리 | `need`(6, 1~30 또는 `"half"`=15, `"third"`=10, `"all"`=30. 방 인원과 상관없이 이 공 수), `opens`(꼭 적는다) | 들어간 파란 공이 `need` 개가 되면 `opens` 가 열린다 |
| `flower` | 꽃. 바닥 바로 위에 한 덩어리 | `hp`(5, 1~30. 쏘여도 되는 횟수), `hold`(40, 5~300. 지킬 초), `opens` | 종을 친 뒤 `hold` 초 동안 쏘인 횟수가 `hp` 를 넘지 않으면 열린다. 다 쏘이면 판이 처음으로 돌아가고 종을 다시 쳐야 한다 |
| `leak` | 새는 바닥. 집 바닥 칸들에(칸 사이에 양동이·거치대가 끼어 있어도 칸들을 감싼 넓이 전체를 센다) | `max`(6, 0~99. 새도 되는 물방울 수), `hold`(40, 5~300), `opens` | 종을 친 뒤 `hold` 초 동안 바닥에 떨어진 빗물이 `max` 를 넘지 않으면 열린다. 넘으면 판이 처음으로 돌아간다 |
| `bucket` | 양동이. 바닥 바로 위 한 칸 | 없음 | 확인으로 들고 내려놓는다. 위로 떨어진 빗물을 12방울까지 받는다(받은 물은 새지 않은 것으로 친다) |
| `drain` | 물 버리는 곳. 바닥 바로 위 칸에 | 없음 | 양동이를 든 채 확인을 누르면 비운다 |
| `sled` | 썰매. 한 칸(그 칸 바닥에 선다) | `opens`(꼭 적는다) | 옆에서 확인을 누르면 그 사람이 타고 오른쪽으로 밀려 출발한다. 곡선과 땅을 따라 중력으로 미끄러지고, 탄 사람이 땅에 닿아 있을 때 뛰기를 누르면 썰매가 뛴다. 표적을 모두 차례대로 지나면 열린다. 1.5초 멈추거나 25초가 지나거나 화면 밖으로 나가면 "썰매가 멈췄어요" 와 함께 처음 자리로 돌아온다 |
| `target` | 표적. 하늘 칸마다(네모) | `order`(1, 1~9 자연수) | 썰매(또는 탄 사람)가 지나가면 켜진다. 앞 차례가 켜져야 다음 차례가 켜진다 |
| `slot` | 홈. 원점 한 칸에만 적는다(**그 칸의 왼쪽 아래가 원점**) | `latex`(홈 모양 식, 꼭 적는다), `a`(0), `b`(4)(홈의 x 범위, -40~40), `tol`(0.4, 0.15~0.8 칸. 허용 오차), `opens` | 조각 곡선이 홈 모양을 `tol` 안에서 따라 0.8초 머물면(떨어지다 지나가도) 쏙 맞물려 그 자리에 박히고 `opens` 가 열린다. 위아래로만 맞춰 보므로 옆 자리와 모양이 맞아야 한다. 조각이 홈 양 끝 밖으로 한 칸 넘게 나가면 안 맞는다 |

`opens` 는 다리(bridge) 글자 목록이다(1~8개). 한 번 열린 다리는 다시 닫히지 않는다. 다리 하나를 여러 장치가 함께 열면 하나만 이뤄도 열린다.

자리 약속(어기면 지도를 받지 않는다)
- `press`, `desk`, `out`, `stand`, `bell`, `bucket`, `drain`, `basket`, `flower` 는 바로 아래가 땅(`#`)이어야 한다.
- 공장은 같은 `factory` 이름의 `press`, `desk`, `out` 이 한 벌이다. 셋 다 있어야 하고, 출구는 공장마다 하나. 공장은 한 스테이지에 넷까지.
- 그래프 장치(공·벌·목표·홈·썰매·거치대·종·양동이)를 쓰려면 공장이 있어야 한다. 공장만 있는 스테이지도 된다(예: 연습 스테이지에서 조각으로 다리를 놓는다).
- 썰매는 한 스테이지에 하나, 양동이도 하나.
- `flower` 나 `leak` 이 있으면 `bell` 이 있어야 한다. `flower` 가 있으면 `hive`, `leak` 이 있으면 `drop`(`kind: "rain"`), `basket` 이 있으면 비가 아닌 `drop` 이 있어야 한다.
- `sled` 와 `target` 은 함께 쓴다. `target` 의 `order` 는 1 부터 빠짐없이(1, 2, 3 …). 같은 차례 표적을 여럿 둘 수 있다.
- `drain` 이 있으면 `bucket` 이 있어야 한다.
- `basket`, `flower`, `out` 은 옆으로 이어 놓은 한 덩어리로만.
- 종이 없는 스테이지에서는 공·벌이 처음부터 온다. 종이 있으면 종을 쳐야 시작한다.

움직임 더
- 바구니가 다 차면 공은 멈춘다(다른 목표가 남아 있으면 계속). 꽃과 새는 바닥은 모두 지켜 내면 판이 멈춘다.
- 오래(12초) 구른 공은 사라진다. 한 번에 날아다니는 공·물방울·벌은 90개까지.
- 판의 알림 글은 정해진 네 가지뿐이다: "썰매가 멈췄어요. 다시 출발해 봐요", "빨간 공이 들어가서 두 개가 빠졌어요", "꽃이 벌에게 다 쏘였어요. 종을 쳐서 다시 해 봐요", "집에 물이 너무 많이 샜어요. 종을 쳐서 다시 해 봐요".

## 새 물건 만들기 (things.json)

판에 있는 장치만으로는 게임 아이디어가 안 담길 때, **물건을 새로 만든다**. 씨앗, 물방울, 동전, 용암, 구름 발판, 바위, 화분처럼 수업에 맞는 물건을 팩 안에서 정의하고 그림을 그려 넣으면, 판이 물리(떨어짐, 막힘, 밟고 서기), 그리기, 여럿이 하는 방의 맞추기를 맡는다. 코드는 쓰지 않는다. 성질을 골라 조합한다.

```json
{
  "seed":   { "name": "씨앗", "sprite": "seed", "size": 3, "body": "carry" },
  "spring": { "name": "용수철", "sprite": "spring", "touch": "bounce", "power": 7 },
  "thorn":  { "name": "가시", "sprite": "thorn", "touch": "hurt" },
  "star":   { "name": "별", "sprite": "star", "touch": "collect" },
  "cloud":  { "name": "구름", "sprite": "cloud", "size": 3, "body": "ledge", "move": { "dx": 3, "speed": 1.5 } },
  "rock":   { "name": "바위", "sprite": "rock", "body": "push", "need": "half" },
  "lamp":   { "name": "등", "frames": ["lamp-off", "lamp-on"], "behavior": "toggle", "opens": ["x"] }
}
```

물건 이름(왼쪽 열쇠)은 영문 소문자, 숫자, 줄표로 40자까지. 팩 하나에 30가지, 한 스테이지에 80개까지 놓는다.

| 칸 | 뜻 |
|---|---|
| `name` | 화면에 쓰는 이름(10자까지). "확인: 씨앗 들기" 처럼 안내에 나온다 |
| `sprite` | 그림 이름(sprites 폴더). 여러 장을 번갈아 보이려면 대신 `frames: ["a", "b"]`(4장까지, 크기가 같아야 한다. 0.25초마다 넘긴다) |
| `size` | 한 점의 크기(px): 1, 2(기본), 3. 15점 × 2px 가 한 칸 |
| `body` | 몸. `"pass"`(기본, 부딪히지 않고 지나간다) · `"solid"`(땅처럼 막히고 위에 선다) · `"ledge"`(발판: 위에서 내려올 때만 딛고, 아래에서는 뚫고 올라간다) · `"push"`(상자처럼 여럿이 민다. 그림 크기를 칸으로 반올림한 상자가 된다) · `"carry"`(확인으로 들고, 다시 확인으로 내려놓거나 놓는 곳에 넣는다. 한 사람이 하나만 든다) |
| `touch` | 닿으면. `"none"`(기본) · `"collect"`(사라지고 그 물건을 받는 놓는 곳의 수가 오른다. body 는 `"pass"`) · `"hurt"`(닿은 도름이가 처음 자리로 돌아간다) · `"bounce"`(튕겨 올린다. `"pass"` 는 닿으면, `"solid"`·`"ledge"` 는 위를 딛으면) |
| `power` | 튕겨 오르는 높이(2~10칸, 기본 5). 맨손 뛰기는 약 3.5칸이다 |
| `move` | 왔다 갔다: `{ "dx": 칸, "dy": 칸, "speed": 1초에 가는 칸 }`. dx 는 -20~20(오른쪽이 +), dy 는 -10~10(아래가 +), speed 0.5~6. 처음 자리와 거기서 dx·dy 만큼 간 자리 사이를 오간다. 단단한 물건·발판 위에 선 도름이는 함께 실려 간다. `push`, `carry` 에는 못 쓴다 |
| `label` | 늘 보이는 이름표(8자까지). 표지(sign)와 달리 멀리서도 보인다 |
| `need` | `push` 를 미는 데 필요한 사람 수(상자의 need 와 같다) |
| `with` / `without` | 이 다리 글자가 켜진 동안만 나타난다 / 사라진다(예: 단추를 밟는 동안만 사라지는 벽) |
| `behavior` | 판이 아는 성질로 안 되는 움직임. `platform/behaviors/` 에 있는 이름(지금: `toggle` 확인으로 켜고 끄기, `timer` 닿으면 켜지고 4초 뒤 꺼짐). 없는 움직임이 필요하면 새로 만든다(`kit/DEVICE_GUIDE.md` '새 움직임') |
| `opens` | `behavior` 가 켠 동안 켜지는 다리 글자 목록 |

움직임
- 든 물건은 머리 위에 보인다. 든 채로 떨어지거나 문에 들어가거나 방에서 나가면 그 물건은 처음 자리로 돌아간다. 내려놓은 물건은 땅·다리·상자·단단한 물건 위까지 떨어진다.
- 놓는 곳에서 받지 않는 물건을 들고 확인을 누르면 "여기에는 놓을 수 없어요"가 보이고 아무 일도 없다. 정답·오답이 아니라 '이 자리에 맞는가'를 몸으로 겪게 하는 장치다.
- 모으는 물건은 다시 나타나지 않는다. 놓는 곳을 여러 개 두면 같은 물건을 받는 곳마다 함께 센다.
- 움직이는 물건의 자리는 시간으로만 정해져 모든 화면에서 같다.

자리 약속
- `pass` 가 아닌 물건의 그림은 땅(`#`)과 겹치면 안 된다.
- 시작 자리 줄은 물건과 놓는 곳을 피해 선다. `@` 오른쪽 여덟 칸은 비워 둔다.
- 왔다 갔다 하는 단단한 물건이 오가는 길에는 땅을 두지 않는다(도름이가 끼인다).

여럿이 해야 하게 만드는 법(예)
- 놓는 곳의 `need` 를 `"all"` 로 두고 물건을 멀리 흩어 둔다: 나눠서 날라야 빠르다.
- 들 수 있는 물건을 단단한 물건 위 높은 곳에 둔다: 친구 머리를 딛어야 닿는다.
- 시간 단추(`timer`)가 연 다리가 4초 뒤 닫힌다: 한 사람이 밟는 동안 다른 사람이 건넌다.
- 다리 글자가 켜진 동안만 사라지는 벽(`without`): 단추를 지키는 사람이 있어야 지나간다.

본보기: 연습 팩 `packs/etc/tutorial` 의 셋째 스테이지(`things.json`, `stages/03.*`).

## 끝나는 조건

열쇠를 든 도름이가 문에 닿으면 문이 열린다. 열린 문 앞에서 확인 단추를 누르면 들어가고, **모든 도름이가 들어가면** 스테이지가 끝난다. 문 안에서 확인을 다시 누르면 나온다(먼저 들어간 친구가 남은 친구를 도우러 나올 수 있다).

## 끝까지 깰 수 있는지 확인

`npm run play:bots -- <교과>/<팩>` 을 돌리면 봇이 가장 적은 인원, 8명, 30명으로 스테이지마다 끝까지 깨 보고 한 줄씩 알려 줘요(`--players 8`, `--stage 01` 로 좁힐 수 있어요). 팩 검사(`npm run check:packs`)도 같은 봇을 돌려 못 깨는 스테이지를 걸러요. 봇은 단추 지키기, 상자 밀기, 친구 한 명 머리 딛기만 해요. 그래프 공장이 있는 스테이지는 봇이 식을 몰라 '확인 못 함'으로 알려 주니, 사람이 직접 깨 보고 풀이 시험(`tests/graph-factory.test.ts`)으로도 확인해요. 새 물건(things.json)이 있는 스테이지도 아직 '확인 못 함'으로 나오니, 2명·8명으로 화면에서 직접 끝까지 깨 보세요. 친구 둘 이상을 쌓아야 하는 길처럼 봇이 못 하는 길만 남으면 '확인 못 함'으로 알려 주니, 그 인원은 화면에서 직접 깨 보세요.

## 조작과 몸

- 움직이기(좌우), 뛰기, 확인 세 가지다. 확인은 열린 문에 들어갈 때, 그래프 공장의 방에서 창을 열 때, 그래프 조각과 양동이를 들고 놓고 꽂고 쏟을 때, 종을 칠 때, 썰매를 출발시킬 때, 새 물건을 들고 놓거나 켜고 끌 때 쓴다. 그래프 공장의 창(식과 숫자를 넣는 칸)만은 키보드로 입력한다(휴대폰과 태블릿에서는 화면에 수식 자판이 뜬다). Enter 를 누르면 넣고, Esc 를 누르면 닫는다.
- 도름이끼리는 서로 막힌다. 옆으로 지나가지 못하고, 머리 위에는 올라설 수 있다. 좁은 길에 여럿을 지나가게 하려면 뛰어넘을 높이를 남긴다.
- 상자는 줄지어 밀어도 된다(앞사람이 밀고 있으면 뒤에 붙어 미는 사람도 센다). 줄 가운데 한 명이 안 밀면 그 뒤는 세지 않는다.
- 머리 위에 친구가 서 있으면 뛰어오르지 못한다.
- 빨간 공에 맞거나 벌에 쏘이면 잠깐(약 1초) 멈춘다.
- 혼자 남으면 못 푸는 자리를 만들지 않는다. 예: 다리를 붙잡는 단추는 건너편에도 하나 둔다.

## 하지 않는 것

- 문제 창, "정답"과 "오답" 문구. 그래프 공장의 식 넣는 창은 문제가 아니라 도구라서 예외다(맞고 틀림을 말하지 않고 모양만 보여 준다).
- 팩 폴더 안에 코드 파일이나 다른 파일을 두는 것. pack.json, DESIGN.md, things.json, stages 폴더(NN.json, NN.map.txt), sprites 폴더(글자 그림 .txt)만 둘 수 있다. 새 움직임 코드는 팩이 아니라 `platform/behaviors/` 에 둔다(`kit/DEVICE_GUIDE.md`).
- 바깥에서 가져온 그림 파일을 그대로 쓰는 것. 스테이지의 그림은 글자 그림으로만 그린다(화풍을 하나로 지키려는 약속). 그림 도구로 뽑은 그림은 `npm run sprite:image` 로 글자 그림으로 바꿔 쓴다(`kit/ART_GUIDE.md`).
- 바깥 주소, 학생 개인정보.

## 설계할 때 알아 둘 수치

판(`platform/sim.ts`, `render.ts`)이 정한 값이다. 지도를 그리기 전에 본다. 한 칸은 30px 이다.

| 알고 싶은 것 | 값 |
|---|---|
| 얼마나 높이 뛰나 | 세 칸 턱은 뛰어오르고 네 칸은 못 오른다. 친구 머리나 상자 하나를 딛으면 네 칸도 오른다 |
| 얼마나 멀리 뛰나 | 세 칸 구덩이는 혼자 뛰어 건넌다. 혼자 못 건너게 하려면 다섯 칸 이상으로 판다 |
| 도름이 크기 | 한 칸보다 좁고(22px) 한 칸보다 크다(38px). 한 칸 틈으로 떨어지고, 한 칸 높이 굴은 못 지나간다 |
| 넓은 단추에 몇 명 서나 | 땅에 선 사람만 센다(친구 머리 위에 선 사람은 안 센다). 30명의 3분의 1(10명)이 서려면 여덟 칸으로 넓힌다 |
| 상자가 빠지는 구멍 | 상자는 자기 너비만 한 구멍에만 빠진다. 두 칸 상자는 한 칸 틈 위를 지나간다. 넓은 상자로 구멍을 건너게 하려면 구멍은 한 칸까지만(더 넓으면 미는 사람이 먼저 빠져 상자가 멈춘다) |
| 상자가 다리 두 칸에 걸치면 | 한 칸이라도 받치고 있으면 안 떨어진다. 받침 두 칸을 서로 다른 단추에 이으면 둘을 같이 밟아야 떨어진다 |
| 사라지는 다리 위의 상자 | 다리가 사라질 때 떨어진다 |
| 상자를 벽에 붙이면 | 상자는 당길 수 없다. 벽이나 다른 상자에 붙여 버리면 다시 못 뗀다. 상자 둘을 나란히 붙여 놓지 않는다 |
| 꾸밈 그림이 가리는 것 | 꾸밈은 땅과 다리 위, 단추와 상자와 도름이 뒤에 그려진다 |
| 한 화면에 보이는 넓이 | 가로 32칸, 세로 18칸. 내 도름이를 따라 움직인다 |
| 30명이 처음 서는 자리 | `@` 오른쪽으로 여덟 칸, 위로 네 칸을 비워 둔다(열 명씩 세 층으로 선다) |
| 2명일 때의 필요 인원 | `"third"`, `"half"` 는 2명이면 1명이 된다. 2명에서도 둘이 꼭 필요하게 하려면 서로 떨어진 단추 둘을 같이 밟게 한다 |
| 표지의 글 | 가까이 가야 보인다. 늘 보여야 하는 이름표로는 쓸 수 없다 |
| 학년(band)과 단원 이름 | 도름스 오락실의 것과 글자까지 같아야 한다. `npm run units` 로 본다 |
