# 선생님이 자기 AI 에게 붙여 넣는 안내문

아래를 그대로 복사해 AI(Claude Code, Codex 등 내 컴퓨터에서 도는 코딩 AI)에 붙여 넣으세요. `dorms.school/world` 의 '게임 만들기'에서도 복사할 수 있어요.

```
도름스 월드에 올릴 협력 게임을 나와 같이 만들자.

1. https://github.com/shinnanchanguk/dorms-world 를 이 컴퓨터에 내려받아 줘(git clone). 이미 있으면 최신으로 맞춰 줘(git pull).
2. 그 폴더에서 kit/skills/coop-game/SKILL.md 를 읽고, 거기 적힌 순서대로 나를 이끌어 줘. 나중에 최신으로 다시 맞추면 그 글을 다시 읽어 줘.
3. 먼저 게임을 내 컴퓨터에 띄워서 화면을 보여 주고, 내 수업 자료를 달라고 하거나 어떤 내용을 게임으로 만들고 싶은지 물어봐 줘.
4. 아이디어는 너도 내고 나도 낼게. 만들기 전에 설계를 같이 정하자.
5. 게임 판의 소스 코드(platform/, src/)와 디자인 규칙(kit/ART_GUIDE.md, platform/look.ts 의 색, platform/ui/ 의 화면 부품)은 다 열려 있어. 판에 없는 물건·장치·규칙이 필요하면 없다고 보고 새로 만들어 줘. 판 코드를 고쳐도 돼. 지금 있는 장치에 맞추려고 아이디어를 줄이거나 바꾸지 마. 디자인 규칙만 지키면 돼. 보내면 운영자가 코드를 살펴보고 판에 맞춰 반영해.
6. 다 만들면 내가 직접 해 본 뒤에 도름스로 보내는 것까지 도와줘(판 코드를 고쳤어도 같은 명령 하나로 함께 가고, GitHub 계정은 필요 없어).
```

알아 두실 것
- 윈도우 컴퓨터와 맥 모두 똑같이 돼요. 안내문도 같아요.
- 필요한 것: 내 컴퓨터에서 도는 코딩 AI, Node.js, Git, 그리고 도름스 계정(교사 인증을 마친 계정). Node.js 와 Git 이 없으면 AI 가 설치를 도와줘요. GitHub 계정은 필요 없어요.
- 수업 자료는 선생님 컴퓨터에서 선생님의 AI 가 읽어요. 도름스로 올라가지 않아요. 다만 선생님이 쓰는 AI 서비스에는 내용이 전달되니 학생 이름, 성적, 연락처가 든 파일은 빼고 주세요.
- 순서: 준비(게임 띄우기) → 자료 읽기 → 아이디어 같이 내기 → 몇 가지 여쭙기 → 브로콜리 점검 → 설계서 확인 → 만들기 → 직접 해 보기 → 검사 → 도름스로 보내기.
- 보낼 때 처음 한 번은 브라우저에 도름스 화면이 열려요. 로그인하고, AI 가 알려 주는 확인 글자를 그 화면에 적은 뒤 '허락'을 누르면 돼요.
- 보내면 운영자에게 도름스 쪽지가 가요. 운영자가 직접 해 보고 승인하면 `dorms.school/world` 와 도름스 오락실에 선생님 이름으로 실리고, 결과는 선생님의 도름스 쪽지로 와요.
- 가는 것은 팩 폴더의 글 파일(설계서, 지도, 그림)이고, 실릴 때 도름스 닉네임이 함께 보여요. 누구나 볼 수 있는 곳에 실리니 학생 이름과 사진은 넣지 마세요.
